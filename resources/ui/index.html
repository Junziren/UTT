UTT

UTILITY TOOLBOX / STEREO UTILITY PROCESSOR

v0.3.1

UTT is a compact native-host utility processor for corrective stereo work: inspect, re-route, balance and document the final output without changing the parameter contract beneath a session.

SIGNAL PATH

DC BLOCK -> PHASE -> GAIN -> M/S -> MONO / WIDTH -> SWAP -> PAN -> OUTPUT. Metering, scope and LUFS read the completed chain.

MEASUREMENT

Post-chain L/R peak and RMS, correlation, a real stereo scope and BS.1770-4 / EBU R128 Momentary, Short-term and Integrated LUFS.

RECORDING

REC captures post-chain stereo as 24-bit WAV. With no custom path, it immediately creates a new take in Music / UTT Recordings.

CONTROL

Knobs support drag, wheel, Shift fine control, double-click reset and keyboard steps. Parameter right-click stays in the native host menu.

AUDIO I/O

Mono or stereo input is processed through the same stereo chain. The plugin exposes stereo and mono-compatible output layouts.

SURFACE

Offline embedded WebView UI with real native meter and scope frames. Preview mode never invents activity or telemetry.

PROJECT

Part of the openFAD family of Chinese-first open-source music visual tools from FAD Records; UTT is developed by UnpureBloom.
